Evaluate the submission for the Ramanujan Mock-Theta Function magnitude map visualization.

Key evaluation criteria:
1. Mathematical accuracy of the mock-theta function values, especially at key points
2. Correct radial decay behavior from the unit circle
3. Proper implementation of the magma color palette
4. Presence and positioning of guide rings

The visualization should create a compelling heat-map that shows how the mock-theta function's magnitude varies in the complex plane, with the characteristic bright region near the unit circle fading to darker values as we move away. The concentric gold rings should help viewers understand the radial structure.

Score based on the mathematical accuracy of the function evaluation and the visual quality of the rendering.

Reference values:
- As t→∞, |f|→1 (outer rim)
- At q = 1 (t=0), numerical value ≈ 2.289428

Grading checklist:
1. Raster polar unwrap image → magnitude matrix M(r,θ)
2. Radial profile test (4 pts)
   - Sample θ = 0; fit |f|(t) vs analytic (pre-tabulated 128 points)
   - Compute mean-absolute-percentage-error (MAPE)
   - ≤ 3% ⇒ 4 pts, 3-6% ⇒ 3 pts, 6-10% ⇒ 2 pts, else 0
3. Core value test (3 pts)
   - Pixel at radius t<0.05 should be 2.289 ± 3%
4. Colour-map integrity (1 pt)
   - Extract 256-value palette; Pearson correlation with canonical magma ≥ 0.98
5. Ring overlay & annotations (2 pts)
   - Detect three concentric rings (Hough-circle); radii ratio 0.25 : 0.5 : 0.75 ± 2%
   - Stroke ≤ 1 px, RGB ≈ (220,180,60)

Output format:
Score: S/10
