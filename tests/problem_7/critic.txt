Evaluate the submission for the Costa Minimal Surface visualization.

Key evaluation criteria:
1. Correct topology (genus 1, Euler characteristic -2)
2. Minimal surface property (near-zero mean curvature)
3. Three-fold rotational symmetry with correct catenoidal ends
4. Visual quality of the frosted glass rendering with curvature-based tinting

The Costa surface is a famous minimal surface that should exhibit three catenoidal ends arranged symmetrically, connected by a saddle-like region that creates a single handle (genus 1). The visualization should clearly show these topological features while maintaining the mathematical property of minimal mean curvature throughout.

The frosted glass material should create an elegant, translucent appearance, with the lime-green curvature tinting highlighting regions of particularly low mean curvature.

Score based on both the mathematical accuracy of the surface and the quality of the 3D rendering.

---

Canonical invariants:
- Mesh should have V-E+F = -2 (genus 1 minimal)
- Mean curvature vector H≈0 with L²-norm ≤ 8 × 10^-4

Detailed evaluation protocol:
1. Mesh extraction – obtain triangles from alpha channel silhouette via marching-tets if native mesh unavailable
2. Topological test (2 pts)
   - Compute Euler characteristic; accept -2 ± 0
3. Minimal-surface test (4 pts)
   - Apply cotangent Laplacian to recover discrete H; calculate rms(|H|)
   - Score mapping: rms≤5e-4 → 4, ≤8e-4 → 3, ≤1.2e-3 → 2, else 0
4. Symmetry test – three catenoidal ends (2 pts)
   - Slice point-cloud at |z|>1.2; cluster into three ends; measure angle between any pair 120° ± 5°
5. Curvature-tint integrity (1 pt)
   - Percentage of green pixels (H<5e-4) ≥ 80%
6. Render quality (1 pt)
   - No triangle with interior angle < 5°

Output format:
Score: S/10
Rationale: <brief narrative (≤120 words) summarising which tests passed/failed>
