WGPU+WGSL Programming Guide - Expected Output Format
===================================================

VERSION: WGSL (WebGPU Shading Language) + WGPU Runtime
TARGET: Mathematical visualization shaders that WORK with WGPU
EXPECTED OUTPUT: Valid WGSL that compiles and renders successfully

⚠️ CRITICAL: Generate EXACTLY this format - WGPU enforces strict validation rules

⚠️ WGSL FORBIDDEN SYNTAX - WILL CAUSE VALIDATION ERRORS
========================================================

❌ FORBIDDEN: Variable array indexing
```wgsl
let vertices = array<vec3<f32>, 8>(/*...*/);
for (var i = 0u; i < 8u; i++) {
    let vertex = vertices[i];  // ❌ ERROR: "may only be indexed by a constant"
}
```

❌ FORBIDDEN: Variable array assignment
```wgsl
var projected: array<vec2<f32>, 8>;
projected[i] = someValue;  // ❌ ERROR: variable indexing in assignment
```

❌ FORBIDDEN: Closures/lambdas (Rust/JS syntax)  
```wgsl
let checkLine = |p0: vec2<f32>, p1: vec2<f32>| -> f32 {  // ❌ ERROR: "expected expression, found '|'"
    return someValue;
};
```

❌ FORBIDDEN: Mutable captures in closures
```wgsl
let updateMin = |dist: f32| {  // ❌ WGSL has no closure syntax
    minDist = min(minDist, dist);
};
```

✅ REQUIRED SOLUTIONS:

1. MANUAL VERTEX EXPANSION (replace arrays):
```wgsl
// Define each vertex explicitly
let v0 = vec3<f32>(-1.0, -1.0, -1.0);
let v1 = vec3<f32>( 1.0, -1.0, -1.0);
let v2 = vec3<f32>( 1.0,  1.0, -1.0);
let v3 = vec3<f32>(-1.0,  1.0, -1.0);
let v4 = vec3<f32>(-1.0, -1.0,  1.0);
let v5 = vec3<f32>( 1.0, -1.0,  1.0);
let v6 = vec3<f32>( 1.0,  1.0,  1.0);
let v7 = vec3<f32>(-1.0,  1.0,  1.0);

// Transform each vertex manually
let p0 = (transform * v0).xy;
let p1 = (transform * v1).xy;
let p2 = (transform * v2).xy;
let p3 = (transform * v3).xy;
let p4 = (transform * v4).xy;
let p5 = (transform * v5).xy;
let p6 = (transform * v6).xy;  
let p7 = (transform * v7).xy;
```

2. FUNCTION CALLS (replace closures):
```wgsl
// Use regular function calls instead of closures
fn checkLineDistance(uv: vec2<f32>, p0: vec2<f32>, p1: vec2<f32>) -> f32 {
    return lineDistance(uv, p0, p1);
}

// Then call function explicitly for each edge:
minDist = min(minDist, checkLineDistance(uv, p0, p1));
minDist = min(minDist, checkLineDistance(uv, p1, p2));
minDist = min(minDist, checkLineDistance(uv, p2, p3));
// ... etc for all edges
```

REQUIRED OUTPUT FORMAT - WGPU-COMPATIBLE WGSL
=============================================

⚠️ YOUR TASK: Generate WGSL shaders that follow this EXACT format for WGPU compatibility:

```wgsl
@vertex
fn main_vs(@builtin(vertex_index) vid: u32) -> @builtin(position) vec4<f32> {
    let x = f32(i32(vid & 1u) * 4 - 1);
    let y = f32(i32((vid >> 1u) & 1u) * 4 - 1);
    return vec4<f32>(x, y, 0.0, 1.0);
}

@fragment  
fn main_fs(@builtin(position) pos: vec4<f32>) -> @location(0) vec4<f32> {
    let uv = (pos.xy - 512.0) / 512.0;
    
    // Rotation matrix
    let c = cos(0.5);
    let s = sin(0.5);
    let rot = mat3x3<f32>(
        vec3<f32>(c, 0.0, s),
        vec3<f32>(0.0, 1.0, 0.0), 
        vec3<f32>(-s, 0.0, c)
    );
    
    // ALL vertices defined explicitly (NO arrays with variable indexing)
    let v0 = rot * vec3<f32>(-0.5, -0.5, -0.5);
    let v1 = rot * vec3<f32>( 0.5, -0.5, -0.5);
    let v2 = rot * vec3<f32>( 0.5,  0.5, -0.5);
    let v3 = rot * vec3<f32>(-0.5,  0.5, -0.5);
    let v4 = rot * vec3<f32>(-0.5, -0.5,  0.5);
    let v5 = rot * vec3<f32>( 0.5, -0.5,  0.5);
    let v6 = rot * vec3<f32>( 0.5,  0.5,  0.5);
    let v7 = rot * vec3<f32>(-0.5,  0.5,  0.5);
    
    // Project to 2D (NO array storage)
    let p0 = v0.xy;
    let p1 = v1.xy; 
    let p2 = v2.xy;
    let p3 = v3.xy;
    let p4 = v4.xy;
    let p5 = v5.xy;
    let p6 = v6.xy;
    let p7 = v7.xy;
    
    // Distance calculations (ALL manual, NO loops with variable indexing)
    var minDist = 1000.0;
    minDist = min(minDist, lineDistance(uv, p0, p1));
    minDist = min(minDist, lineDistance(uv, p1, p2));
    minDist = min(minDist, lineDistance(uv, p2, p3));
    minDist = min(minDist, lineDistance(uv, p3, p0));
    minDist = min(minDist, lineDistance(uv, p4, p5));
    minDist = min(minDist, lineDistance(uv, p5, p6));
    minDist = min(minDist, lineDistance(uv, p6, p7));
    minDist = min(minDist, lineDistance(uv, p7, p4));
    minDist = min(minDist, lineDistance(uv, p0, p4));
    minDist = min(minDist, lineDistance(uv, p1, p5));
    minDist = min(minDist, lineDistance(uv, p2, p6));
    minDist = min(minDist, lineDistance(uv, p3, p7));
    
    // Render wireframe
    let lineWidth = 0.02;
    let cubeColor = vec3<f32>(0.0, 0.6, 1.0);
    let bgColor = vec3<f32>(0.1, 0.1, 0.1);
    let alpha = 1.0 - smoothstep(0.0, lineWidth, minDist);
    let finalColor = mix(bgColor, cubeColor, alpha);
    
    return vec4<f32>(finalColor, 1.0);
}

fn lineDistance(p: vec2<f32>, a: vec2<f32>, b: vec2<f32>) -> f32 {
    let pa = p - a;
    let ba = b - a;
    let h = clamp(dot(pa, ba) / dot(ba, ba), 0.0, 1.0);
    return length(pa - ba * h);
}
```

CRITICAL REMINDER
=================

If you see "may only be indexed by a constant" - you have used variable array indexing.
The solution is ALWAYS manual expansion. There are no exceptions or workarounds.

WGSL is designed for GPU parallelism and prohibits many dynamic patterns that work in CPU code.

QUICK REFERENCE: ERROR PATTERNS → SOLUTIONS
============================================

| Error Message Pattern | Root Cause | Solution |
|----------------------|------------|----------|
| "may only be indexed by a constant" | Variable array indexing: `array[i]` | Manual expansion - define each element explicitly |
| "expected expression, found '\|'" | Lambda/closure syntax | Use regular functions instead |
| "variable assignment" + array | Variable array assignment: `array[i] = x` | Manual expansion - assign each element explicitly |
| "naga::Expression" validation | Variable indexing in expression | Unroll loops, use explicit element access |

COMMON ANTI-PATTERNS TO AVOID
==============================

❌ DON'T: Loop with variable array access
```wgsl
let values = array<f32, 10>(/* ... */);
for (var i = 0; i < 10; i++) {
    let v = values[i];  // ERROR!
}
```

✅ DO: Unroll loops or use explicit access
```wgsl
let v0 = 1.0;
let v1 = 2.0;
let v2 = 3.0;
// ... etc for all values

// Then use them explicitly:
var result = v0 + v1 + v2 + ...;
```

❌ DON'T: Store in arrays then iterate
```wgsl
var heights: array<f32, 10>;
for (var i = 0; i < 10; i++) {
    heights[i] = computeHeight(i);  // ERROR!
}
```

✅ DO: Compute and use directly
```wgsl
let h0 = computeHeight(0);
let h1 = computeHeight(1);
let h2 = computeHeight(2);
// ... etc

// Use directly in calculations:
minDist = min(minDist, distanceToBar(uv, h0));
minDist = min(minDist, distanceToBar(uv, h1));
// ... etc
```
