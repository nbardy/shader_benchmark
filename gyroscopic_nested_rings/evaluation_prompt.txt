**Inputs**

1. *Spec* – the generation prompt for Problem 213.
2. *Candidate* – the PNG produced by the renderer.

**Task** Return an integer **S** (1‑10) plus a ≤ 180‑word rationale.

**Expected features**

* Euler angles measure exactly 30° ± 2° on correct axes.
* Rings share common centre within 0.5 %.
* No ring intersects another (clearance ≥ 0.05).

**Scoring**

| Aspect       | Pts | Checks                                      |
| ------------ | --- | ------------------------------------------- |
| Angles       | 0‑3 | 30° rotations about orthogonal axes ± 2°.  |
| Centring     | 0‑2 | Common center within 0.5%.                 |
| Intersection | 0‑2 | No ring intersections, clearance ≥ 0.05.   |
| Render       | 0‑3 | Colors (#f66, #6f6, #66f), camera, quality. |

**Output format**

```
Score: S/10
Rationale: <text>
```
