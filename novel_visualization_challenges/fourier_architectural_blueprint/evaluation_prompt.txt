**Inputs**

1. *Spec* – the generation prompt for Fourier Architectural Blueprint.
2. *Candidate* – the PNG produced by the renderer.

**Task** Return an integer **S** (1‑10) plus a ≤ 180‑word rationale.

**Expected visual cues**

* Blueprint style: white lines on deep blue background with technical drawing aesthetic
* Multiple circular floors stacked vertically, each representing a frequency component
* Floor radius proportional to Fourier amplitude |F(k)|
* Column arrangements reflect frequency (2π|k| columns per floor)
* Helical ramps connecting floors based on phase relationships
* Harmonic bridges between related frequencies
* Proper isometric projection with hidden line handling
* Architectural annotations and frequency labels
* Grid paper texture and technical shadows

**Scoring rubric**

| Aspect                     | Pts | Explicit checks                                                           |
| -------------------------- | --- | ------------------------------------------------------------------------- |
| **Blueprint aesthetic**    | 0‑2 | White on blue, proper line weights, technical drawing style               |
| **Fourier mapping**        | 0‑3 | Floor sizes match amplitudes; column count reflects frequency             |
| **Structural connections** | 0‑2 | Helical ramps present; harmonic bridges connect related floors            |
| **Technical accuracy**     | 0‑2 | Isometric projection correct; hidden lines dashed; annotations readable   |
| **Visual clarity**         | 0‑1 | Clear hierarchy of elements; no visual confusion                          |

**Output format**

```
Score: S/10
Rationale: …
```
