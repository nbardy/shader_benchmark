**Inputs**

1. *Spec* – the generation prompt for Problem 011.
2. *Candidate* – the PNG produced by the renderer.

**Task** Return an integer **S** (1‑10) plus a ≤ 180‑word rationale.

**Expected visual cues**

* A dense "cotton‑ball toroid" in which **every visible loop is a perfect circle**; no ellipses.
* Nested tori: smallest (dark blue) near the projection line, largest (magenta–red) outer shell.
* Radial hue change matches longitude—clockwise cycling cyan → green → yellow → red → magenta → blue once around.
* No fibres cross or break; transparency allows at least three concentric tori to be simultaneously visible.
* Grey legend sphere at lower‑right with clearly visible latitude/longitude grid.

**Scoring rubric**

| Aspect                       | Pts | Explicit checks                                                            |

| **Circularity**              | 0‑3 | Randomly sample 100 fibres; each fits a 3‑D circle with RMS error < 1 %.   |

| **Colour–longitude mapping** | 0‑2 | Hue drift around one full cycle ≤ ±10 °.                                   |
| **Completeness/density**     | 0‑2 | ≥ 300 k fibre points; no visible holes larger than 3 % of object diameter. |
