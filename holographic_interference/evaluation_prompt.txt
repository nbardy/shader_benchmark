**Task** Return an integer **S** (1‑10) plus a ≤ 180‑word rationale.

**What the correct pattern looks like**

* Straight vertical fringes (parallel to the y‑axis) spanning the full domain; edges terminate cleanly at the black border.
* For each channel, bright–bright spacing

  $
    \Lambda_c=\frac{\lambda_c}{2\sin10^{\circ}}
  $

  so the 10 λ$_G$‑wide domain contains **exactly 3 bright peaks and 3 dark gaps** for green, 2.3 periods for red, 2.1 for blue (fractional peaks visible at edges).
* Superposition yields repeating rainbow sequence **cyan → green → yellow → red → magenta → blue**, cycling left‑to‑right.
* Fringe contrast 100 %: pure black minima, pure colour maxima.
* No moiré, no curvature (<0.1 px deviation from straightness).
