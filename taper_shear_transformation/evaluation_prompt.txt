**Inputs**

1. *Spec* – the generation prompt for Taper and Shear Transformation.
2. *Candidate* – the PNG produced by the renderer.

**Task** Return an integer **S** (1‑10) plus a ≤ 180‑word rationale.

**Expected visual cues**

* Cylindrical tower with clear quadratic taper (wide base, narrow top).
* Visible lean from shear transformation (0.3, 0.1) per unit.
* 20 distinct floor divisions with architectural detail.
* Glass-to-metal material gradient from bottom to top.
* Window grid with scattered illuminated offices.
* Realistic reflections and environment mapping.
* Ground plane reflection showing building base.

**Scoring rubric**

| Aspect                    | Pts | Explicit checks                                                             |
| ------------------------- | --- | --------------------------------------------------------------------------- |
| **Taper accuracy**        | 0‑3 | Measure radius at 5 heights; verify s(z) = 1-0.6(z/4)².                   |
| **Shear transformation**  | 0‑2 | Linear displacement verified; (0.3, 0.1) per unit height.                  |
| **Architectural detail**  | 0‑2 | 20 floors visible; proper window grid alignment.                           |
| **Material rendering**    | 0‑2 | Glass/metal gradient; reflections physically accurate.                      |
| **Lighting/environment**  | 0‑1 | Sun shadows present; ground reflection visible.                            |

**Output format**

```
Score: S/10
Rationale: …
```
