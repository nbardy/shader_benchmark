# Problem 35: Truncated Icosahedron (Soccer Ball)

## Description
Create a truncated icosahedron (the classic soccer ball shape) with 12 regular pentagonal faces and 20 regular hexagonal faces. Apply the traditional black and white pattern where pentagons are black and hexagons are white, with black edges between all faces.

## Requirements

1. **Geometry**:
   - Accurate truncated icosahedron shape
   - 32 faces total (12 pentagons, 20 hexagons)
   - 60 vertices, 90 edges
   - Unit radius

2. **Pattern & Coloring**:
   - Black pentagons
   - White hexagons
   - Black seams/edges between panels
   - Accurate face detection for coloring

3. **Material Properties**:
   - Leather-like surface
   - Slight specular reflection
   - Subtle surface texture
   - Realistic soccer ball appearance

4. **Animation**:
   - Slow multi-axis rotation
   - Shows all faces clearly
   - Smooth, continuous motion

## Technical Constraints
- Use SDF or mesh-based approach
- Implement face classification algorithm
- Create seamless pattern transitions
- Maintain geometric accuracy
